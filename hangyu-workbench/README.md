# 航屿 (Hangyu OS) · 船长的人生与战略工作台

「航屿」是一套采用毛玻璃器物美学（浅色晨雾 / 深色夜航双模式）、本地优先（Local-First）的个人战略与生活操作系统。围绕**工作与治理、日知与学习、生活与家庭、自媒体创作**四大航道构建。

## 核心舱室架构

1. **我的一天（主工作台）**：可排序、可调节尺寸的 Bento 卡片矩阵（跨国航线气象、日历与手动航标、数字助理与快捷甲板、待办要事圆环、便签/习惯/汇率/日知四栏信息流）。
2. **日程管理**：专注锚定战略闭门、跨国差旅与休整日，不与日常即时通讯日历混杂。
3. **待办事项**：四大人生领域树、艾森豪威尔四象限、自然语言速记与内置番茄专注舱。
4. **笔记知识库**：支持 `[[双向链接]]`、反向引用追踪与知识关系图谱可视化。
5. **日知与智库**：06:00–07:05 十四栏早间订阅核验矩阵、立式书脊进度书架与印尼语日常/商务闪卡。
6. **自媒体工坊**：微信公众号、小红书、AI评论专栏与小说创作流水线，支持一键复制移动端排版与脱敏护栏检查。
7. **汇率与量化**：CNY / IDR / USD 即时牌价换算、私密收支潮汐账本与 IDX LQ45 均线信号/持仓净盈亏测算。
8. **习惯追踪**：印章式每日节奏打卡与连续复利统计。
9. **战略项目**：遵循「经营战略 → 组织能力 → 方案治理 → 高密汇报 → 落地闭环」五级推导，支持 PPT 与逐页讲稿分离交付跟踪。
10. **人生罗盘**：每周「三件重点」极简复盘 + 人生之轮 8 大核心维度动态雷达图。
11. **工具箱**：科学计算器、会议悬浮倒计时窗、逐页讲稿语速/A4页数测算、跨国四地时区对齐罗盘、意式浓缩萃豆实验台与 JSON 校验。
12. **设置与数据**：浅深主题、6 套强调色（含日知森绿与远洋深青）、字号密度、本机差旅备忘匣与全量 JSON 备份导入/导出。

## 本地启动

```bash
cd hangyu-workbench
npm install
npm run dev
```

生产构建与静态检查：

```bash
npm run lint
npm run build
```
